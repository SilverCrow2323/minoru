# NOTICE — about the art in minoru/assets/

The code in this repository (everything under `minoru/*.lua`, `main.lua`,
`conf.lua`, `tests/`) is MIT-licensed — see LICENSE. Use it, fork it, drop
it into your own project.

The PNGs under `minoru/assets/` (helmet, limbs, icons, accessories) depict
**Minoru⁶**, an original character from its creator's own fiction/setting
("Arret" / the Rintrompo universe). That artwork is **not** covered by the
MIT license above and is not released for reuse — if you want a floating
helmet-robot assistant for your own project, the *engine* (rig.lua,
visor.lua, dialogue.lua, persona.lua, sync.lua, the whole rig/anchor/
accessory system) is designed to work with a replacement art kit of your
own in the same folder layout; you don't need Minoru's own look to use it.

If you're not sure whether a particular use is fine, ask before assuming.
